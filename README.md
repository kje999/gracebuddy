## Features
- **52-Week Complete Curriculum**: Chronological scope from Creation to Revelation.
- **Offline Multi-Version Scripture Engine**: Integrated 312 verified Scripture texts across 6 major translations (WEB, KJV, NIV, ESV, NKJV, NLT).
- **Dynamic Translation Adaptation**: Seamless runtime version switching for dashboard, memory verse, printables, and projector slides.
- **Interactive Verse Garden**: Gamified scripture memorization with blooming flower mechanics.
- **Teacher Command Center**: Quick attendance roster, PDF guides, and classroom projector remote.
- **Polished Dark & Light Modes**: Consistent high-contrast styling across all modules.
